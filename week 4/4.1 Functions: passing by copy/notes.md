you can make a function by defining its data type and input parameters. 

e.g {data type} {name of function}({data type of input 1}{name of input 1}, ...)

then define what the function does and return an output to the console. 

This new function can now be called later using {name of function}({argument assigned to input 1},repeat for other inputs)

passing by copy means that you send a variable to a function and the program creates a seperate duplicate of that value in memory. The function then gets a copy of this value
